툴 검교정 매니저 v4.5 — 툴 라벨·SMAX 화면 자동 반영

[툴 라벨과 SMAX 화면 함께 업로드]
같은 사진 선택에서 툴 교정 사진과 SMAX 화면을 함께 추가할 수 있습니다.
교정 사진은 Label Photo에, SMAX 화면은 SMAX Tool Photo에 자동 저장합니다.
SMAX의 Serial/Asset Number를 엑셀 Serial과 정확히 대조합니다. SGPN/Tool Code/Excel Asset #를 대신 사용하지 않습니다.
영문 Tool Owner를 읽어 표시하며, 등록 시리얼로 엑셀의 한글 담당자를 연결합니다.
SMAX의 Calibration Due Date는 Cal Next에 반영합니다. 날짜가 불명확하면 사진만 저장하고 기존 날짜를 유지합니다.
SMAX의 Created By/Last Modified는 교정일이 아니므로 Cal Last에 넣지 않습니다. SMAX만 올릴 때 Cal Last는 유지합니다.
같은 툴의 교정 사진 1장과 SMAX 화면 1장은 한 번에 반영합니다. 같은 칸 사진 중복이나 두 차기일의 충돌은 보류합니다.
SMAX 열이 없으면 해당 화면을 다른 사진 칸에 넣지 않습니다.
수동 검토 시 사진 저장 위치와 SMAX 차기일 반영 체크를 확인할 수 있습니다.

[4.5 라벨과 날짜 재탐색]
작은 글자 안의 흰 구멍을 라벨로 잘못 선택해 넓은 탐색이 생략되던 문제를 개선했습니다.
검출 라벨 이외에도 상단 영역을 따로 재탐색합니다.
연도 일부나 제목만 읽힌 경우 날짜 끝자리가 잘리지 않도록 영역을 확장하고, 실패하면 넓은 영역을 다시 읽습니다.
이름이 정확하면 4자리 번호 조각도 동일 담당자의 툴 목록과 대조할 수 있습니다.
독립적인 두 번의 명확한 인식, 전체 번호의 40% 이상, 담당자 내 후보 한 개, 완전한 두 날짜와 엑셀 주기가 모두 맞아야 자동 연결합니다.
비슷한 다른 숫자를 정답으로 바꾸지 않고, 날짜의 누락된 일을 추측하지 않습니다.
인식이 계속 실패하면 사진 아래 [인식 진단 ZIP 저장]으로 원본 사진과 인식 원문·좌표·신뢰도를 한 파일로 저장할 수 있습니다.
이 진단 ZIP에는 회사 엑셀·회사 링크·다른 사진·파일 핸들은 포함하지 않으며 자동으로 전송하지 않습니다.

[4.4 이름·시리얼 재인식]
날짜는 읽었지만 이름·시리얼이 안 읽혔을 때 상단 라벨을 따로 찾아 다시 인식합니다.
떨어져 붙은 이름과 시리얼 표지를 한 문단으로 읽고 끝내지 않도록 후보 영역을 각각 읽습니다.
같은 물리적 행의 글자가 OCR 원문에서 줄바꿈으로 분리되면 좌표와 실제 문자를 대조합니다.
앞자리 0을 보존하며, 잘못 읽은 끝자리나 이름을 엑셀 값으로 임의 치환하지 않습니다.
정확한 식별 근거가 생기면 기존 날짜와 함께 자동 저장합니다. 충돌한 번호는 계속 보류합니다.

[흐릿한 새 사진과 일부 시리얼 대조]
읽힌 연속 번호 조각을 등록된 전체 툴 목록과 비교합니다.
기본적으로 최소 6글자·전체 번호의 60% 이상이 서로 다른 재인식에서 두 번 이상 명확히 읽혀야 합니다.
이름도 정확하면 최소 5글자·50%로 비교할 수 있습니다.
후보가 한 개이며 사진의 두 날짜와 해당 툴의 엑셀 교정 주기까지 맞으면 부분 시리얼로 자동 연결합니다.
읽지 못한 부분은 등록 번호를 사용합니다. 앞자리 0을 실제 읽었다고 판단하거나 잘못 읽힌 숫자를 임의로 바꾸지 않습니다.
겹치는 후보·다른 명확한 번호·날짜 충돌·너무 적은 글자는 자동 저장하지 않습니다.
완전히 흐리거나 가려져 판독할 정보가 없는 사진의 매칭은 보장할 수 없습니다.

[4.3 자동 매칭 개선]
이름만 읽혔어도 해당 엔지니어의 툴이 여러 개이면 시리얼을 추가 인식합니다.
작은 라벨은 원본 크기 영역을 다시 읽고, 표 테두리 안쪽 숫자 열을 따로 읽어 과한 확대·테두리 간섭의 오독을 줄입니다.
시리얼이 안 읽힌 경우에도 이름과 사진의 두 날짜가 명확하고, 그 간격이 엑셀에서 같은 담당자의 툴 한 개에만 일치하면 자동 연결합니다.
토크렌치 6개월/멀티미터 12개월뿐 아니라 엑셀의 다른 장주기를 그대로 사용합니다.
사진에 명시한 차기일이 있으면 해당 날짜를 Cal Next에 저장합니다.

[확인된 매칭 기억]
정확한 독립 근거로 매칭되거나 사용자가 직접 확인한 툴의 인식 패턴을 이 브라우저에 기억합니다.
다음 사진에서 같은 이름·시리얼의 근접 오독 패턴을 활용합니다. 모델을 새로 훈련하는 기능은 아닙니다.
사진/교정 날짜/회사 링크는 이 기억에 저장하지 않습니다. 다른 PC와 자동 공유되지는 않습니다.
엑셀의 담당자·시리얼·주기가 바뀌면 예전 매칭을 적용하지 않습니다.
동일한 패턴이 다른 툴과 충돌하면 활용을 중단합니다. 앞자리 0을 임의로 붙이거나 지우지 않습니다.
[확인된 매칭 기억]을 끄거나 [기억 초기화]로 기록을 지울 수 있습니다.

[4.2 날짜 자동 반영]
사진에 붙은 라벨의 [교정일자]는 엑셀의 [Cal Last]에 저장합니다.
라벨의 [차기교정예정일자]는 엑셀의 [Cal Next]에 저장합니다.
예: 교정일자 2025.12.29 → Cal Last 2025-12-29 / 차기교정예정일자 2026.12.29 → Cal Next 2026-12-29.
이름 또는 고유 시리얼로 엔지니어의 툴 행을 찾은 뒤 두 날짜와 사진을 함께 반영합니다.
OneDrive 연결 모드는 선택한 파일에 자동 저장합니다. 직접 파일 선택 모드는 수정본을 만듭니다.
작은 표의 라벨·날짜는 글자 위치를 함께 확인하고, 필요하면 날짜 영역을 확대해서 다시 읽습니다.
날짜가 서로 다르게 읽히거나 유효하지 않으면 자동 저장하지 않습니다.
첨부 엑셀의 실제 시리얼·교정 라벨 사진으로 과거 날짜를 사진 날짜로 갱신하는 검사를 통과했습니다.
라벨이 작아 문구를 읽지 못하면 두 번 일치한 날짜를 사용합니다. 이름·시리얼 없이 날짜만 있는 사진은 자동으로 담당자를 결정하지 않습니다.

[4.1 인식 엔진 수정]
기존 프로그램은 파일로 열 때 blob:null/...#core.js 로딩이 실패할 수 있었습니다.
별도 코어 스크립트를 불러오지 않고 같은 워커에 내장해 시작하도록 변경했습니다.
새 ZIP의 압축을 풀고 새 Tool-Manager.html을 여세요. 프로그램 화면의 버전 4.5를 확인하세요.
엔진 오류가 나면 이름·시리얼 입력을 요구하지 않고 [인식 엔진 다시 시작]을 제공합니다.
직접 입력 화면은 사용자가 [직접 입력으로 진행 (선택)]을 누른 경우에만 엽니다.
인쇄 라벨의 실제 OCR과 날짜·사진 자동 반영은 테스트했습니다. 실제 손글씨 사진은 별도 정확도 확인이 필요합니다.

[처음 한 번]
1. Teams의 파일 탭에서 [SharePoint에서 열기]를 누르거나 회사 SharePoint에서 엑셀의 문서 라이브러리를 엽니다.
2. [동기화] 또는 [OneDrive에 바로 가기 추가]로 이 PC의 OneDrive에 연결합니다.
3. 파일 탐색기에서 동기화된 엑셀을 확인합니다. 단순히 다운로드 폴더로 받은 복사본과 구분하세요.
4. 프로그램을 Chrome 또는 Edge에서 열고 [OneDrive 엑셀 한 번 연결]을 눌러 그 파일을 선택합니다.
5. 브라우저의 파일 읽기·쓰기 권한을 허용합니다. 이후에는 엑셀을 끌어다 놓지 않습니다.

[이후 작업]
사진만 선택하세요. 정확히 인식된 툴의 교정일·다음 교정일·사진을 같은 파일에 자동 저장합니다.
프로그램은 사진 추가 때마다 최신 파일을 다시 읽고, 다른 변경이 확인되면 덮어쓰지 않습니다.
OneDrive 서버로의 업로드는 PC의 OneDrive가 수행합니다. 녹색 체크 등 동기화 상태를 확인하세요.
저장 성공 표시는 이 PC의 파일 저장 결과이며 회사 서버 반영 확인은 아닙니다.

[재실행]
연결 파일 핸들을 이 브라우저가 기억합니다. 권한 재확인이 필요하면 [권한 다시 연결]을 누르세요.
브라우저 저장소를 지우거나 다른 PC/브라우저/프로그램 위치에서 열면 다시 연결해야 할 수 있습니다.

[백업과 충돌]
원본을 바꾸기 직전의 백업 1개를 브라우저 저장소에 보관한 뒤 저장합니다. [저장 전 백업 받기]로 받을 수 있습니다.
백업 보관에 실패하면 원본 자동 저장을 중단하고 수정본 다운로드를 제공합니다.
다른 사람이 파일을 변경했다는 메시지가 나오면 [최신 파일로 다시 처리·저장]으로 재검토합니다.
Excel이 파일을 잠갔다면 Excel을 닫고 다시 시도하세요. OneDrive의 동시 원격 편집까지 잠그지는 못합니다.

[회사 링크]
공유 링크는 프로그램의 [회사 링크 보관]에 붙여넣어 보관할 수 있습니다. 이 브라우저에만 저장됩니다.
링크는 회사 문서를 여는 용도이며, 링크만으로 인증/쓰기 권한이 생기지 않습니다.
선택한 파일이 올바른 회사 엑셀의 동기화 파일인지 확인하세요. 프로그램은 OneDrive 경로/서버 연결을 검증할 수 없습니다.

[수동 방식]
연결 없이 엑셀을 직접 선택하기에서 파일을 선택하면 자동 저장 연결을 해제하고 수정본 다운로드 방식으로 사용합니다.

인식이 멈추면 [인식 중지]를 누르고 다시 인식할 수 있습니다.
화면에 실패 이유와 진행 상태가 표시됩니다.
채팅 미리보기에서 막히면 [프로그램 HTML 저장]으로 PC에 저장하여 Chrome/Edge에서 여세요.
파일 저장도 차단되면 [다운로드가 막히면]→전체코드복사→메모장 붙여넣기:
파일 이름 Tool-Manager.html / 파일 형식 모든 파일 / 인코딩 UTF-8.

시리얼은 하나의 툴과 정확히 일치할 때 연결합니다.
이름만 읽혔을 때에는 그 담당자의 툴이 하나인 경우에만 연결합니다.
이름·시리얼·날짜가 충돌하거나 불확실한 사진, 중복 사진 등은 확인 대상으로 남깁니다.
날짜는 교정일·차기 교정일 라벨을 읽습니다. 차기일 표기가 없고 교정일만 명확하면 엑셀 주기로 계산합니다.
읽을 수 없는 차기일 표기가 있을 때에는 계산으로 덮지 않고 보류합니다.

확인 대상은 사진과 항목·날짜를 보정하고 확인 체크→보정한 내용 반영을 누르세요.
자동 모드를 끄면 모든 사진을 직접 확인하는 방식으로도 쓸 수 있습니다.
변경 내역 저장에는 반영된 항목과 보류 이유가 기록됩니다.
사진 인식은 브라우저에서 처리합니다. 선택한 파일과 저장 전 백업은 자동 저장을 위해 다룹니다. 서버 동기화는 PC의 OneDrive가 수행합니다.
새로고침하거나 창을 닫으면 현재 목록이 사라집니다. 수정본을 먼저 저장하세요.
손글씨·흐릿한 사진의 인식 성공을 보장하지 않습니다. 수정본을 Excel에서 확인하세요.
