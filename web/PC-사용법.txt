툴 검교정 매니저 7.2 — PC 마무리 버전

프로그램: https://geonwook-kang.github.io/Tool-management-/pc.html
사용 안내: https://geonwook-kang.github.io/Tool-management-/pc-guide.html

[PC에서 시작]
1. PC의 Chrome 또는 Edge에서 프로그램 주소를 엽니다.
   내려받은 ZIP을 사용할 때는 압축을 풀고 Tool-Manager.html을 여세요.
2. 관리 엑셀 연결 버튼으로 사용할 .xlsx 파일을 한 번 선택합니다.
   이 PC의 일반 폴더 또는 OneDrive로 동기화한 회사 폴더에서 선택할 수 있습니다.
   읽기·쓰기 권한을 요청하면 허용하고 화면에 연결된 파일 이름을 확인하세요.
3. 사진 선택으로 툴 라벨 사진·SMAX 캡처를 추가합니다. 여러 장을 선택할 수 있습니다.
4. 인식과 자동 저장이 끝나면 각 사진의 저장 완료 표시를 확인합니다.
   확인이 필요한 사진만 사진 속 번호·날짜와 엑셀 항목을 대조하세요.

같은 브라우저는 연결한 파일을 기억합니다. 브라우저가 다시 권한을 요청하면 허용하세요.
파일을 이동하거나 브라우저 데이터를 지우면 다시 연결해야 할 수 있습니다.
Excel에서 같은 파일을 열어 저장을 막고 있다면 해당 파일을 닫은 뒤 다시 처리하세요.

[이름이 없어도 시리얼로 매칭]
사진의 전체 시리얼이 엑셀의 한 툴을 식별하면 이름이 안 보여도 등록 담당자와 연결합니다.
담당자 이름은 시리얼로 찾은 엑셀 행의 등록값을 자동으로 가져옵니다. 사진에 이름이 없어도 됩니다.
이름이 먼저 확실히 읽히면 해당 담당자의 툴 목록에서 남은 번호를 비교합니다. 같은 담당자의 후보가 여러 개면 추가 확인합니다.
마모로 일부 숫자가 안 보일 때는 실제로 읽힌 번호 조각을 엑셀 전체 목록과 대조합니다.
독립적으로 반복 확인한 번호 조각이 충분하고 후보가 하나이며 날짜·검교정 주기 등 근거가 맞으면 자동 매칭합니다.
등록된 전체 번호와 담당자 이름은 엑셀의 값을 유지합니다. 안 보이는 숫자를 새로 써 넣지 않습니다.
짧거나 여러 툴에 공통인 번호, 서로 다른 명확한 번호·이름, 불분명한 날짜는 자동 저장을 보류합니다.
사진에는 가능한 한 시리얼과 교정표가 함께 보이게 찍어 주세요. 모든 마모·흐림을 복원할 수는 없습니다.

[사진과 날짜가 들어가는 위치]
툴 라벨의 교정일자             → Cal Last
툴 라벨의 차기교정예정일자     → Cal Next
툴 라벨 사진                  → Label Photo
SMAX 화면의 Serial/Asset Number → 엑셀 Serial과 대조
SMAX 화면                     → SMAX Tool Photo
SMAX의 Calibration Due Date    → Cal Next
SMAX의 작성·수정 일시는 Cal Last로 사용하지 않습니다.
토크렌치·멀티미터와 다른 툴의 주기는 엑셀에 등록된 값을 사용합니다.

[빠른 처리]
명확한 번호·날짜는 필요한 영역부터 읽고, 근거가 충분하면 불필요한 추가 인식을 끝냅니다.
글자 크기·사진 크기에 따라 원본 회색조 영역을 여러 크기로 읽고, 번호가 확인되면 추가 재시도를 끝냅니다.
인식 엔진은 다음 사진에서도 재사용합니다. 이미 확인한 날짜를 이름 누락 때문에 반복해서 읽지 않습니다.
처리 시간은 사진 크기·해상도·마모·PC 성능에 따라 달라집니다.
인식용 전처리로 엑셀에 넣는 원본 사진을 임의로 보정하거나 번호를 완성하지 않습니다.

[저장 방식 확인]
PC 파일 연결 모드는 선택한 .xlsx 파일에 저장합니다. 저장 전 백업과 파일 변경 검사를 사용합니다.
OneDrive 동기화 폴더를 골랐다면 서버 반영은 PC의 OneDrive가 수행합니다.
프로그램의 PC 파일 저장 완료와 OneDrive 서버 동기화 완료는 각각 확인하세요.
이 PC에 실제로 동기화되지 않은 SharePoint 웹 주소만으로 PC 파일 연결을 대신할 수 없습니다.

원본 파일 연결을 지원하지 않는 브라우저에서는 이 기기에 엑셀 사본을 보관하는 방식을 선택할 수 있습니다.
이 경우 회사 원본은 자동 변경되지 않습니다. 처리한 엑셀을 내려받아 원하는 위치에 반영하세요.
화면의 저장 위치와 완료 메시지를 확인하면 원본 연결과 기기 사본을 구별할 수 있습니다.

[문제가 있을 때]
저장 충돌·파일 잠금·권한 오류는 완료로 표시하지 않습니다. 안내를 확인한 뒤 최신 파일로 다시 처리하세요.
인식 엔진 오류가 표시되면 엔진 재시도를 사용하세요. 손으로 이름을 먼저 입력할 필요는 없습니다.
특정 사진이 계속 실패하면 해당 사진의 인식 진단 ZIP을 저장해 원본과 인식 결과를 확인할 수 있습니다.
현재 작업 화면에 저장하지 않은 사진이 있으면 창을 닫기 전에 저장 결과를 확인하세요.

이 버전은 PC 작업을 중심으로 정리했습니다. 휴대폰·Microsoft 365 공동 저장은 기존 별도 버전으로 남겨 두었습니다.
PC 사진 인식에는 별도의 앱 ID·OCR API 키가 필요하지 않습니다. OCR 엔진과 한글·영문 모델은 프로그램에 내장되어 있습니다.
회사 엑셀·업로드 사진·개인 공유 링크·로그인 정보는 공개 배포 파일에 포함하지 않습니다.
