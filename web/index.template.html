작동하지 않을 때 / 사용 안내
Chrome이나 Edge 일반 창에서 저장한 HTML을 여세요. 채팅 미리보기는 브라우저의 보안 정책 때문에 사진 인식을 막을 수 있습니다. 화면의 오류 원문을 확인하세요. 인식이 멈추면 인식 중지 후 다시 시도하거나 자동 모드를 끄고 수동으로 반영할 수 있습니다.
고유 시리얼 또는 툴이 하나인 담당자 이름으로 자동 연결합니다. 교정일과 차기 교정일의 라벨·인식 신뢰도를 확인하고 처리합니다. 동일 툴 사진이 여러 장이거나 이름·날짜가 충돌하면 보류합니다.
