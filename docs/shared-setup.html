TOOL MANAGER · 공동 저장

담당자가 한 번 연결하고,
직원은 사진만 올리세요.

휴대폰과 PC에서 같은 SharePoint 엑셀 원본에 사진과 교정 날짜를 저장합니다. 직원마다 엑셀 경로나 앱 ID를 입력하지 않습니다.

직원이 사용할 때

  1. 담당자가 보내 준 공동 작업 링크를 엽니다. Android는 Chrome, iPhone은 Safari를 사용하세요.
  2. 요청되면 회사 계정으로 로그인합니다. 지정된 엑셀이 자동으로 연결됩니다.
  3. 사진 촬영 또는 앨범에서 선택으로 올립니다. 인식 결과가 일치하면 원본에 저장되며, 불확실한 사진은 확인을 요청합니다.

Android의 Chrome 메뉴에서 앱 설치·홈 화면에 추가, iPhone의 Safari 공유 메뉴에서 홈 화면에 추가를 선택하면 앱 아이콘으로 열 수 있습니다. 담당자에게 받은 공동 작업 링크에서 추가하세요.

회사 로그인 세션이 만료되면 다시 로그인이 필요할 수 있습니다. 지정된 엑셀 연결은 유지됩니다.

담당자: 최초 연결

  1. 사용할 SharePoint .xlsx 원본의 공유 링크를 준비합니다. 사진을 올릴 직원에게 이 원본의 편집 권한이 있어야 합니다.
  2. 아래 담당자 화면을 노트북의 Chrome 또는 Edge에서 엽니다.
    담당자 연결 화면 열기
  3. 등록된 애플리케이션(클라이언트) ID를 입력합니다. 테넌트 ID는 선택 항목이며 비워 두면 organizations를 사용합니다. 단일 테넌트 앱이면 해당 회사의 테넌트 ID를 입력하세요.
  4. 설정을 저장하고 회사 계정으로 로그인한 뒤 SharePoint 엑셀 링크를 입력하여 공동 저장을 연결합니다.
  5. 화면에서 생성된 공동 작업 링크를 복사하여 직원에게 보냅니다. 직원에게 담당자 설정 주소나 SharePoint 엑셀 링크만 보내는 방식과 구분해 주세요.

담당자와 직원 모두 생성된 공동 작업 링크를 즐겨찾기나 홈 화면에 저장하세요. 브라우저 데이터를 지웠거나 새 기기를 사용할 때도 이 링크로 다시 연결할 수 있습니다.

앱 ID는 OneDrive 아이디인가요?

앱 ID는 이 프로그램을 Microsoft에 등록한 번호입니다. 회사 이메일이나 OneDrive 로그인 아이디와 다릅니다. 회사 이메일은 Microsoft 로그인 화면에서 사용합니다.

애플리케이션(클라이언트) ID
Microsoft Entra의 앱 등록에서 확인하는 공개 식별자입니다. 담당자가 최초 연결할 때 한 번 입력합니다.
디렉터리(테넌트) ID
회사 Microsoft 365 조직을 나타내는 식별자입니다. 등록한 앱의 개요 화면에서 확인할 수 있습니다.

비밀번호나 클라이언트 비밀키를 입력하거나 공유하지 마세요. 이 앱은 비밀키 없이 회사 계정으로 로그인합니다.

등록된 앱 ID가 없다면

  1. Microsoft Entra 관리 센터의 앱 등록 → 새 등록에서 회사 계정용 앱을 등록합니다. 지원 계정 유형은 회사 정책에 맞게 선택합니다.
  2. 인증 → 플랫폼 추가 → SPA(단일 페이지 애플리케이션)에 다음 회신 주소를 정확하게 등록합니다. https://geonwook-kang.github.io/Tool-management-/shared.html 주소 끝에 ?setup=1이나 #workspace=…를 붙이지 않습니다. 로그인은 인증 코드 + PKCE 방식을 사용합니다.
  3. API 사용 권한 → Microsoft Graph → 위임된 권한에서 Files.ReadWrite.All을 추가합니다. 로그인 시 openid, profile도 요청합니다. 애플리케이션 권한이나 클라이언트 비밀키를 만들 필요는 없습니다.
  4. 개요 화면의 클라이언트 ID와 필요한 경우 테넌트 ID를 담당자 연결 화면에 입력합니다.

회사 정책에 따라 앱 등록·사용자 동의가 제한될 수 있습니다. 실제로 ‘관리자 승인 필요’가 표시되거나 등록 권한이 없을 때 회사 IT에 등록·동의를 요청하세요.

연결을 유지하는 방법

프로그램은 담당자의 회사 OneDrive에 작은 공동 설정 JSON 파일을 만들고 회사 내부 읽기 전용으로 공유합니다. 이 파일에는 저장할 엑셀의 위치가 들어 있습니다. 엑셀과 사진은 계속 지정한 SharePoint 원본에 저장됩니다.

공동 설정의 변경 권한은 담당자에게 있습니다. 직원은 공동 작업 링크로 이 설정을 읽으며, 원본 엑셀에 대한 편집 권한은 각 계정에 필요합니다. 링크만으로 원본 편집 권한이 생기지는 않습니다.

담당자의 설정 JSON을 삭제하거나 공유를 해제하면 직원 연결에 영향을 줍니다. 로그인 토큰과 비밀번호는 공동 작업 링크나 설정 파일에 넣지 않습니다.

나중에 엑셀 경로를 바꾸려면

  1. 진행 중인 사진 업로드를 마치고 담당자 계정으로 기존 공동 작업 링크를 엽니다.
  2. 담당자 설정에서 새 SharePoint 엑셀 링크를 입력해 저장 대상을 변경합니다. 현재 창에 미저장 사진이 있으면 먼저 저장하거나 목록에서 제거합니다.
  3. 기존 직원용 공동 작업 링크는 그대로 사용합니다. 직원 앱은 다음 연결·저장 전에 최신 설정을 확인합니다. 새 원본에도 직원의 편집 권한이 있어야 합니다.

동시에 같은 툴의 사진·날짜를 바꾸거나 저장 대상이 변경된 경우 확인을 요청할 수 있습니다. 완료 표시를 확인한 뒤 사진 작업을 마치세요.
