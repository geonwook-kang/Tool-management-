# 휴대폰 앱의 회사 Excel 연결 설정

이 안내는 Android와 iPhone에서 사진을 올린 뒤 **같은 SharePoint·OneDrive Excel 원본에 저장**하기 위한 Microsoft 365 연결 설정입니다. Teams의 파일 탭에 있는 문서도 실제 저장 위치는 SharePoint일 수 있습니다.

앱은 사용자가 회사 Microsoft 계정으로 로그인한 후, 그 계정으로 접근할 수 있는 Excel 파일을 읽고 수정합니다. Excel 다운로드 사본을 만드는 기능과 회사 원본에 저장하는 기능은 구분됩니다.

## 1. 먼저 앱의 HTTPS 주소를 정합니다

휴대폰의 홈 화면 설치와 Microsoft 로그인에는 실제로 접속할 수 있는 HTTPS 주소가 필요합니다. 다운로드한 HTML 파일의 `file://` 주소는 Microsoft 로그인 리디렉션 주소로 사용할 수 없습니다.

다음 주소는 **게시 후 등록할 주소의 예시**입니다. 게시·접속 확인이 끝났다는 뜻은 아닙니다.

```text
https://geonwook-kang.github.io/Tool-management-/index.html
```

회사에서 허용한 다른 HTTPS 서버에 앱을 게시해도 됩니다. 회사 서버를 사용한다면 이후 단계에도 그 실제 주소를 사용합니다.

앱의 Microsoft 365 연결 설정에 표시되는 **리디렉션 URI**를 확인하세요. 기본값은 현재 열린 앱 주소에서 로그인 응답의 쿼리·해시를 제외한 주소입니다. Entra에 등록하는 값과 앱에서 사용하는 값은 정확히 같아야 합니다. 예를 들어 `/Tool-management-/`와 `/Tool-management-/index.html`은 서로 다른 경로입니다. 앱을 열고 홈 화면에 설치할 때도 등록한 경로를 일관되게 사용하세요. 와일드카드나 로그인 후 돌아갈 임의의 외부 주소를 등록하지 않습니다.

## 2. Microsoft Entra에 SPA 앱을 등록합니다

회사에서 앱 등록 권한이 있는 사용자 또는 IT 담당자가 진행합니다.

1. [Microsoft Entra 관리 센터](https://entra.microsoft.com/)에서 회사 테넌트를 선택합니다.
2. **앱 등록 → 새 등록**을 엽니다.
3. 이름을 입력합니다. 예: `Tool Calibration Manager`.
4. 회사 내부용이면 지원되는 계정 유형을 **이 조직 디렉터리의 계정만**으로 선택합니다.
5. 리디렉션 URI 플랫폼을 **SPA(단일 페이지 애플리케이션)**로 선택합니다.
6. 1단계에서 확인한 실제 HTTPS 리디렉션 URI를 그대로 입력하고 등록합니다.

등록 후 **개요**에서 아래 두 값을 확인합니다.

| Entra에 표시되는 값 | 앱 설정에 넣는 값 |
|---|---|
| 디렉터리(테넌트) ID | Tenant ID |
| 애플리케이션(클라이언트) ID | Client ID |

이 두 ID는 공개 클라이언트 설정값입니다. **클라이언트 비밀 값(Client Secret), 인증서 개인 키, 회사 비밀번호는 앱 설정에 넣지 않습니다.** 이 앱은 브라우저의 공개 SPA 클라이언트로 연결하며, 모바일 앱에 비밀 키를 내장하는 방식으로 사용하지 않습니다.

## 3. 사용자가 위임하는 Microsoft Graph 권한을 설정합니다

등록한 앱에서 **API 사용 권한 → 권한 추가 → Microsoft Graph → 위임된 권한**을 선택합니다.

| 권한 | 사용하는 이유 |
|---|---|
| `Files.ReadWrite.All` | 로그인한 사용자가 접근 가능한 회사 문서의 읽기·쓰기 |
| `openid` | 회사 계정 로그인 |
| `profile` | 로그인한 계정의 기본 프로필 표시 |

사용자 없이 실행하는 **애플리케이션 권한**으로 등록하지 않습니다. 이 앱은 사용자의 로그인을 전제로 합니다.

`Files.ReadWrite.All`을 추가해도 사용자가 원래 수정할 수 없던 파일의 권한이 새로 생기지는 않습니다. 사용자는 대상 Excel 파일의 **편집 권한**을 가지고 있어야 합니다.

회사의 사용자 동의 정책이 허용하면 첫 로그인에서 필요한 동의를 진행할 수 있습니다. 회사 정책 때문에 관리자 승인 화면이 나오면, IT 담당자가 이 앱의 권한과 대상 사용자를 확인한 뒤 해당 테넌트에서 승인해야 합니다. 앱이 회사의 접근 정책을 대신 변경하지는 않습니다.

## 4. 앱에서 로그인하고 회사 Excel 원본을 연결합니다

1. 실제 게시된 HTTPS 앱을 엽니다.
2. Microsoft 365 연결 설정에 **Tenant ID**, **Client ID**, 실제 **리디렉션 URI**를 입력합니다.
3. 회사 Microsoft 계정으로 로그인합니다.
4. SharePoint·OneDrive에서 대상 Excel 파일의 **공유 → 링크 복사**로 HTTPS 링크를 복사하고 앱에 입력해 연결합니다. 링크는 사용하는 기기의 앱 설정에 입력하며, 공개 소스나 배포 파일에 넣지 않습니다. 회사의 별도 도메인으로 문서를 열었던 주소가 Microsoft Graph에서 해석되지 않으면, 문서의 공유 메뉴에서 새로 복사한 링크로 연결합니다.
5. 앱에 표시된 파일 이름을 확인합니다. 처음에는 회사 문서에서 테스트용 사본을 만들어 연결해 동작을 확인하는 방법을 권장합니다.
6. 사진 한 장을 업로드하고 담당자·시리얼·날짜·사진 저장 위치와 저장 결과를 확인합니다.

툴 교정 사진은 `Cal Last`, `Cal Next`, `Label Photo`를 갱신합니다. SMAX 화면은 `SMAX Tool Photo`에 넣고, 명확히 읽힌 `Calibration Due Date`를 `Cal Next`에 반영합니다. SMAX의 작성·수정 일시로 `Cal Last`를 바꾸지 않습니다.

화면의 **사진 인식 완료**, **기기에 수정본 준비**, **회사 파일 저장 완료**는 같은 상태가 아닙니다. Microsoft 365 연결과 서버 저장이 성공한 경우에만 회사 원본이 저장됐다고 판단하세요. 다른 사용자의 변경과 충돌하거나 편집 권한이 없으면 오류를 확인하고 최신 파일로 다시 처리해야 합니다.

로그인 접근 토큰은 현재 앱 메모리에만 보관합니다. 앱을 닫거나 토큰이 만료되면 다시 로그인해야 할 수 있습니다. 이 설정은 앱이 닫힌 상태에서 계속 사진을 받아 회사 문서를 수정하는 백그라운드 서비스가 아닙니다.

## 5. 휴대폰 홈 화면에 설치합니다

- **Android:** Chrome으로 실제 HTTPS 앱을 연 뒤 브라우저의 **앱 설치** 또는 **홈 화면에 추가**를 사용합니다.
- **iPhone:** Safari로 실제 HTTPS 앱을 연 뒤 **공유 → 홈 화면에 추가**를 사용합니다.

휴대폰에서도 앱의 촬영 버튼 또는 사진 선택 버튼으로 사진을 올릴 수 있습니다. 설치 메뉴의 문구와 위치는 기기·브라우저 버전에 따라 다를 수 있습니다.

## 연결 오류를 확인할 때

| 표시 또는 현상 | 확인할 내용 |
|---|---|
| `AADSTS50011` 또는 리디렉션 불일치 | 앱에 표시된 실제 URI와 Entra의 SPA URI가 스킴·호스트·경로까지 같은지 확인합니다. |
| 앱을 찾을 수 없거나 다른 조직 계정이라는 오류 | Tenant ID와 Client ID가 같은 회사 앱 등록의 값인지 확인합니다. |
| 관리자 승인이 필요하다는 화면 | 해당 회사 테넌트의 앱 동의 정책과 이 앱의 위임 권한을 IT 담당자가 확인합니다. |
| 로그인은 되지만 문서에 접근할 수 없음 | 같은 계정으로 SharePoint·Teams에서 대상 문서를 열고 편집할 수 있는지 확인합니다. |
| 이 기기·브라우저에서 로그인을 허용하지 않음 | 회사에서 요구하는 기기와 브라우저 조건을 IT 담당자에게 확인합니다. |
| 회사 파일이 저장되지 않았다고 표시됨 | 인식 결과와 서버 저장 결과를 구분하고, 네트워크·권한·최신 파일의 변경 여부를 확인합니다. |

사진 인식은 기기 안에서 수행합니다. **회사 원본을 읽고 저장하는 Microsoft 365 연결에는 인터넷이 필요합니다.** 공개 웹 서버에는 앱 코드가 게시되며, 이 연결 방식에서 사진·Excel 데이터는 사용 중인 기기와 Microsoft 365 사이에서 전달됩니다. 회사 테넌트 로그인과 실제 휴대폰 저장 성공은 각 회사의 계정·파일·기기 환경에서 확인해야 합니다.
