툴 검교정 매니저 7.2 · PC 사용 안내

엑셀을 한 번 연결하고, 다음부터 사진만 올리세요.

이름이 안 보이더라도 고유 시리얼로 등록된 툴을 찾습니다. 일부 숫자가 지워졌을 때는 충분한 번호 조각을 반복 확인해 전체 엑셀 목록과 대조합니다.

PC 프로그램 열기 PC용 ZIP 받기

처음 시작할 때

  1. PC의 Chrome 또는 Edge에서 프로그램을 엽니다. ZIP을 받았다면 압축을 풀고 Tool-Manager.html을 여세요.
  2. 관리 엑셀 연결 버튼으로 사용할 .xlsx 파일을 선택하고 읽기·쓰기 권한을 허용합니다. PC의 일반 폴더와 OneDrive로 동기화한 회사 폴더를 사용할 수 있습니다.
  3. 화면에 연결된 파일 이름을 확인하고 사진 선택으로 툴 사진·SMAX 캡처를 추가합니다. 여러 장도 가능합니다.
  4. 각 사진의 저장 완료 표시를 확인합니다. 불확실한 사진만 사진 속 번호·날짜와 엑셀 항목을 대조하세요.

브라우저는 파일 연결을 기억합니다. 다시 권한을 요청하면 허용하세요. 파일 이동이나 브라우저 데이터 삭제 후에는 다시 연결해야 할 수 있습니다.

이름·시리얼이 일부 지워졌을 때

이름은 필수 조건이 아닙니다. 전체 시리얼이 한 툴을 식별하면 엑셀에 등록된 담당자를 연결합니다.

일부 번호만 보일 때는 실제로 읽힌 조각의 길이·반복 확인·전체 등록 목록의 유일성·교정 날짜와 주기를 함께 확인합니다. 등록 번호를 추측해 고치거나 다른 사람의 비슷한 번호를 임의로 선택하지 않습니다.

짧거나 공통인 번호, 서로 다른 명확한 시리얼·이름, 불명확한 날짜는 확인이 필요합니다. 가능한 한 시리얼과 교정표가 함께 보이게 촬영해 주세요.

원본 저장과 기기 사본 구분

PC 파일 연결은 선택한 실제 파일에 저장합니다. 저장 전 백업과 파일 변경 검사를 사용하며, 저장이 실패하거나 충돌하면 완료로 표시하지 않습니다.

OneDrive 동기화 폴더를 선택했다면 서버로 올리는 작업은 PC의 OneDrive가 수행합니다. 프로그램의 PC 파일 저장 완료와 OneDrive 동기화 완료를 각각 확인하세요.

이 기기에 엑셀 보관 방식은 브라우저 사본을 갱신합니다. 회사 원본은 자동 변경되지 않으므로 처리한 엑셀을 내려받아 반영해야 합니다. 화면의 저장 위치를 확인하세요.

SharePoint 웹 주소만으로 PC 파일 선택을 대신할 수 없습니다. 공유 문서를 PC 폴더에 동기화해 선택하거나 PC에 있는 관리 파일을 사용하세요.

처리와 오류 안내

명확한 번호·날짜는 필요한 영역부터 읽고, 근거가 충분하면 추가 인식을 끝냅니다. 인식 엔진은 다음 사진에서도 재사용합니다. 사진 상태와 PC 성능에 따라 시간은 달라집니다.

파일 잠금이 표시되면 Excel의 같은 파일을 닫은 뒤 다시 처리하세요. 인식 엔진 오류는 재시도로 복구하고, 특정 사진이 계속 실패하면 그 사진의 인식 진단 ZIP을 저장해 확인할 수 있습니다.

PC 사진 인식에는 별도의 앱 ID·OCR API 키가 필요하지 않습니다. 휴대폰과 Microsoft 365 공동 저장은 기존 별도 버전으로 남겨 두었습니다.
