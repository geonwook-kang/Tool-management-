TOOL MANAGER · SharePoint 설치판 5.2

회사 SharePoint에서 사진만 올리기

담당자가 사이트에 한 번 설치하고 관리 엑셀을 지정하면, 직원은 회사 로그인으로 사진을 촬영하거나 선택할 수 있습니다. 직원에게 앱 ID를 입력하라고 묻지 않습니다.

1. PC에서 설치 파일 받기

아래 파일을 PC에 저장하세요. 휴대폰에 직접 설치하는 APK 파일이 아니라, SharePoint 사이트에 추가하는 설치 파일입니다.

SharePoint 설치 파일 받기설치 안내·소스 ZIP 받기

2. 앱 카탈로그에 설치하기

회사에서 사용하는 앱 카탈로그 → SharePoint용 앱(Apps for SharePoint)을 열어 받은 .sppkg 파일을 업로드합니다. 표시되는 사용(Enable app)·배포(Deploy) 안내를 진행하세요.

엑셀을 올리는 일반 문서(Documents) 폴더에 파일을 올리는 것으로는 프로그램이 설치되지 않습니다.

회사에 따라 사이트용 또는 조직용 앱 카탈로그를 사용합니다. 메뉴가 없거나 실제 오류가 나오면 그 화면을 확인해 다음 경로를 정합니다. 문서 편집 권한만으로 설치 메뉴가 반드시 보인다고 가정하지 않습니다.

3. 팀 사이트 페이지에 앱 추가하기

사용할 팀 사이트의 사이트 콘텐츠 → 새로 만들기 → 앱에서 Tool Manager SharePoint를 추가합니다. 사이트에 새 페이지를 만들거나 기존 페이지를 편집하고, 본문의 ＋에서 툴 검교정 매니저를 찾아 추가하세요.

4. 엑셀을 한 번 지정하고 페이지 공유하기

추가한 툴 매니저의 연필(편집) 버튼을 누릅니다. 관리 엑셀 → SharePoint 엑셀 링크 또는 사이트 안의 파일 경로에 이 사이트에 있는 엑셀 링크를 붙여 넣고 적용합니다.

연결된 파일 이름을 확인한 뒤 게시(Publish)하고, 이 SharePoint 페이지 링크를 직원들에게 보내세요. 직원은 휴대폰에서 이 링크를 열고 사진 촬영 또는 앨범에서 선택만 하면 됩니다.

직원이 휴대폰에서 사용할 때

  1. 게시된 SharePoint 페이지를 Android의 Chrome 또는 iPhone의 Safari에서 엽니다. 로그인 화면이 나오면 평소 회사 계정으로 로그인합니다.
  2. 공유 엑셀의 파일 이름과 연결됨 표시를 확인합니다.
  3. 사진을 올린 뒤 회사 공유 원본 저장 완료 결과까지 확인합니다. 인식 결과만 표시된 상태와 원본 저장 완료는 구분합니다.

교정일자 → Cal Last, 차기교정예정일자 → Cal Next로 저장합니다. 툴 사진은 Label Photo, SMAX 화면은 SMAX Tool Photo에 넣습니다.

공유할 주소는 회사 SharePoint 페이지입니다. 공개 GitHub 앱 주소는 설치 파일·안내용입니다. 그 공개 주소가 회사 SharePoint의 로그인 쿠키를 가져와 사용하지는 않습니다.

실제 오류가 표시되면

401: 같은 SharePoint 페이지에서 다시 로그인합니다. 403: 현재 계정으로 대상 엑셀을 편집할 수 있는지 확인합니다. 404: 같은 사이트의 파일 링크를 확인합니다.

412: 다른 사용자가 변경한 원본을 덮어쓰지 않았습니다. 최신 파일로 다시 처리하세요. 409·423: 다른 저장 작업이 끝난 뒤 다시 읽습니다.

앱 시작·스크립트 실행 오류: 페이지를 다시 열고 실제 오류 문구를 확인합니다. 사이트의 콘텐츠 보안 정책(CSP)으로 스크립트나 인식 엔진이 제한되는지도 확인할 수 있습니다.

저장 결과 불확실: 자동 재전송하지 않습니다. 원본과 기기에 보관한 저장 전 백업을 확인합니다.

자세한 설치·오류 안내 보기 · 공개 앱·다운로드 안내로 돌아가기

사진 인식은 기기에서 처리합니다. 회사 파일 읽기·저장에는 인터넷과 현재 계정의 편집 권한이 필요합니다. 실제 회사 사이트 설치와 다른 직원의 휴대폰 접근 여부는 사용 환경에서 확인합니다. 설치 파일에는 회사 엑셀·사진·로그인 정보를 넣지 않습니다.
