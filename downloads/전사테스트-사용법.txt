툴 검교정 매니저 — 전사 파일 테스트판 7.2-T1

이 판은 회사 전체 엑셀을 PC에서 읽고 별도 수정본을 만드는 테스트용입니다.
회사 SharePoint·Teams 원본 또는 선택한 PC 파일에 직접 저장하지 않습니다.
현재 창의 메모리에서 처리하므로 창을 닫기 전에 결과 엑셀을 다운로드하세요.

1. ZIP의 압축을 풀고 Tool-Manager-Company-Test.html을 Chrome 또는 Edge에서 엽니다.
2. 전사 엑셀 선택 버튼으로 암호 없는 .xlsx 파일을 선택합니다. 최대 250 MiB입니다.
3. 시트·툴·기존 사진 수, 지원하지 않는 시트, 중복 시리얼 안내를 확인합니다.
4. 테스트할 툴 라벨 사진 또는 SMAX 캡처를 추가합니다.
5. 인식된 담당자·시리얼·교정 날짜와 처리 결과를 확인합니다.
6. 테스트 결과 엑셀 받기로 _전사테스트_수정본_날짜.xlsx 파일을 다운로드합니다.
7. 다운로드한 사본을 Excel에서 열어 Cal Last, Cal Next, Label Photo 또는
   SMAX Tool Photo의 해당 행과 다른 시트가 유지됐는지 확인합니다.
8. 테스트 보고서 받기로 읽기·변환 결과와 확인이 필요한 내용을 JSON으로 보관할 수 있습니다.

사진은 이 PC에 내장된 인식 엔진으로 읽습니다. 엑셀과 사진을 서버로 전송하지 않습니다.
기존 운영판의 연결 파일·기기 보관 엑셀·인식 기억과 별도로 작동합니다.
중복된 시리얼이나 불확실한 날짜는 임의의 행에 반영하지 않습니다.
툴 관리 열이 없는 시트는 사진을 반영할 대상으로 사용하지 않고 기존 내용을 유지합니다.

필요한 열: Cal Next, Cal Last, Serial, Asset #, Label Photo
선택 열: Cal Interval, Cal Cycle, Manufacturer, Model, Description, SMAX Tool Photo
사진 위치: 교정 사진 → Label Photo / SMAX 캡처 → SMAX Tool Photo
날짜 위치: 교정일자 → Cal Last / 차기교정예정일자 → Cal Next

큰 파일은 초기 읽기·무결성 검사·수정본 생성에 시간이 걸립니다.
250 MiB 이내 압축 파일, 압축 해제 합계 1 GiB 이내, 내부 구성 20,000개 이하를 지원 범위로 제한합니다.
실제 처리 가능 여부와 시간은 파일 구성 및 PC 메모리에 따라 달라집니다.
브라우저 저장 완료는 PC 원본·회사 원본 저장 완료를 뜻하지 않습니다.

첨부된 전사 파일은 이 작업 환경의 32 MiB 전송 한도를 넘어 제작자가 직접 열어 검증하지 못했습니다.
따라서 이 테스트판은 해당 파일의 성공을 미리 보장하는 배포본이 아닙니다.
PC에서 파일을 선택한 뒤 표시되는 결과와 테스트 보고서로 실제 파일의 처리 여부를 확인해 주세요.
