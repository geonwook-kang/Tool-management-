툴 검교정 매니저 5.2 · SharePoint 회사 로그인으로 사용

[직원]
담당자가 게시한 회사 SharePoint 페이지를 Android Chrome 또는 iPhone Safari에서 엽니다.
회사 로그인이 나오면 평소 계정으로 로그인하고 지정 엑셀의 연결됨 표시를 확인합니다.
[사진 촬영] 또는 [앨범에서 선택]으로 사진만 올리세요. 앱 ID·테넌트 ID·경로를 입력하지 않습니다.
교정일자 → Cal Last, 차기교정예정일자 → Cal Next, 사진 → Label Photo 또는 SMAX Tool Photo에 저장합니다.
회사 공유 원본 저장 완료 결과까지 확인합니다. 사진 인식은 기기에서, 회사 파일 저장은 온라인으로 처리합니다.

[담당자: 처음 한 번]
1. PC에서 Tool-Manager-SharePoint-5.2.sppkg를 받습니다.
2. 회사 앱 카탈로그 → SharePoint용 앱(Apps for SharePoint)에 업로드하고 사용·배포 안내를 진행합니다.
3. 팀 사이트의 사이트 콘텐츠 → 새로 만들기 → 앱에서 Tool Manager SharePoint를 추가합니다.
   사이트 페이지를 편집해 + 버튼에서 [툴 검교정 매니저] 웹 파트를 추가합니다.
4. 웹 파트 연필 버튼 → 관리 엑셀 → SharePoint 엑셀 링크 또는 사이트 안의 파일 경로에
   해당 사이트의 .xlsx 링크를 붙여 넣고 적용합니다. 파일 이름을 확인하고 페이지를 게시합니다.
   이 SharePoint 페이지의 링크를 직원들에게 공유하세요.
설치 안내: https://geonwook-kang.github.io/Tool-management-/sharepoint-install.html
자세한 안내: SharePoint-setup.md

.sppkg는 휴대폰 APK가 아니라 SharePoint 사이트 설치 파일입니다.
일반 문서(Documents) 폴더에 올리는 것만으로는 프로그램이 설치되지 않습니다.
카탈로그·설치 메뉴는 회사 사이트 구성에 따라 다릅니다. 표시된 실제 메뉴와 오류를 기준으로 확인합니다.
모든 문서 편집자가 사이트 앱을 설치할 수 있다고 가정하지 않습니다.

[로그인과 실제 결과]
SharePoint 설치판은 현재 사이트의 회사 로그인 세션을 사용하며 별도 Entra 앱 등록·Graph 권한 요청을 추가하지 않습니다.
사전에 회사 승인이 필수라고 가정해 막지 않고 실제 연결 결과를 표시합니다.
401은 현재 SharePoint 페이지에서 회사 로그인을, 403은 해당 계정의 파일 편집 가능 여부를 확인합니다.
412는 원본 변경 충돌로 덮어쓰지 않은 결과입니다. 최신 파일을 다시 읽고 처리합니다.
409·423은 파일 사용 중·잠금 상태입니다. 다른 저장 작업이 끝난 뒤 다시 읽습니다.
앱 시작·스크립트 실행 오류가 나오면 실제 문구와 사이트 콘텐츠 보안 정책(CSP)을 확인합니다.
저장 전 백업은 기기에 보관하며, 저장 결과가 불확실하면 자동 재전송하지 않습니다.

[공개 웹앱과 PC판]
공개 앱 주소: https://geonwook-kang.github.io/Tool-management-/index.html
공개 GitHub 주소는 회사 SharePoint와 다른 사이트입니다. 그 주소에서 회사 로그인 쿠키를 가져와 쓰지 않습니다.
앱 ID 없이 회사 로그인으로 직접 저장하는 설치판은 게시된 SharePoint 페이지를 열어 사용합니다.
공개 PWA·PC판·고급 Microsoft 365 연결도 계속 제공합니다. 고급 연결은 Microsoft365-setup.md를 참고하세요.
공개 PWA는 Android Chrome 앱 설치·홈 화면 추가, iPhone Safari 공유 → 홈 화면에 추가로 설치합니다.
ZIP 안의 HTML 파일을 휴대폰에서 여는 것은 앱 설치가 아닙니다.
PC판은 ZIP을 풀고 Tool-Manager.html을 Chrome 또는 Edge에서 엽니다.

[검증 범위]
동일 출처 앱·로그인 세션 요청, 실제 사진 OCR·OOXML 저장·백업·버전 충돌을 자동 검사합니다.
회사 SharePoint 응답은 통제된 테스트이며 실제 회사 사이트 설치와 직원의 물리 휴대폰은 사용 환경에서 확인합니다.
회사 엑셀·사진·공유 URL·로그인 쿠키·토큰은 설치 파일에 넣지 않습니다.
