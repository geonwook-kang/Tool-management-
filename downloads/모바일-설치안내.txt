툴 검교정 매니저 5.3 · 휴대폰에서 바로 실행

프로그램 열기: https://geonwook-kang.github.io/Tool-management-/direct.html
사이트에 앱을 설치하거나 앱 ID를 입력하지 않고 프로그램 화면을 바로 열 수 있습니다.

[처음 한 번]
1. Android는 Chrome, iPhone은 Safari에서 위 주소를 엽니다.
2. [관리 엑셀 처음 한 번 선택]을 눌러 관리 엑셀(.xlsx)을 선택합니다.
   휴대폰 파일 앱의 OneDrive 위치에서 고르거나, SharePoint에서 내려받은 파일을 고를 수 있습니다.
3. [사진 촬영] 또는 [앨범에서 선택]으로 사진을 올립니다.
4. 이름·시리얼과 매칭된 날짜·사진을 이 기기의 엑셀 사본에 자동 저장합니다.
다음 실행 때 같은 기기·브라우저에 저장된 엑셀을 불러옵니다. 매번 파일을 선택하지 않습니다.
다른 파일을 쓰려면 [엑셀 바꾸기]를 누릅니다.

[저장 위치]
휴대폰 기본 바로 실행 방식은 이 기기에 저장합니다. 회사 SharePoint 원본은 자동 변경하지 않습니다.
[엑셀 공유] 또는 엑셀 저장 버튼으로 수정본을 내보낼 수 있습니다.
회사 원본에 반영하려면 수정본을 직접 업로드하거나 실제로 연결된 회사 저장 방식을 사용해야 합니다.
기기에 기억한 엑셀은 다른 직원의 휴대폰으로 자동 공유되지 않습니다.
브라우저 앱 데이터를 삭제하기 전에는 수정본을 내보내 보관하세요.

[홈 화면에서 앱처럼 열기]
Android: Chrome 메뉴 → 앱 설치 또는 홈 화면에 추가.
iPhone: Safari 공유 메뉴 → 홈 화면에 추가.
설치 없이 브라우저에서 바로 사용해도 됩니다.
ChatGPT·Teams 안의 브라우저에서 촬영·파일 선택이 제한되면 Chrome·Safari로 주소를 여세요.

[PC에서 파일로 실행]
Tool-Manager-Direct-5.3.zip을 풀고 Tool-Manager.html을 Chrome 또는 Edge에서 엽니다.
Python·OCR API 키를 설치하지 않아도 됩니다. 휴대폰에서는 위 프로그램 주소를 사용하세요.
기존 PC OneDrive 동기화 파일 연결, 유효하게 설정된 회사 원본 연결도 유지합니다.
PC 파일 저장 완료와 서버 동기화 완료는 OneDrive에서 구분해 확인합니다.

[인식 결과]
교정일자 → Cal Last, 차기교정예정일자 → Cal Next에 반영합니다.
툴 라벨은 Label Photo, SMAX 화면은 SMAX Tool Photo에 넣습니다.
SMAX는 Serial/Asset Number로 매칭하고 확인된 Calibration Due Date를 Cal Next에 반영합니다.
불확실한 사진·중복·충돌 결과는 확인이 필요합니다.
사진 인식은 기기에서 처리하며 회사 엑셀·사진·공유 URL을 공개 프로그램에 넣지 않습니다.

[선택 기능]
SharePoint 사이트 설치판 5.2는 별도 선택 기능으로 남아 있습니다.
바로 실행 프로그램을 쓰기 위해 .sppkg를 설치할 필요는 없습니다.
고급 회사 원본 연결은 해당 연결이 실제로 완료된 경우에만 원본을 갱신합니다.

[검증 범위]
실제 사진 OCR·엑셀 날짜/사진 반영·기기 사본 저장·백업을 브라우저로 검사합니다.
휴대폰 화면은 브라우저 에뮬레이션이며 물리 휴대폰·실제 회사 계정 접근 확인과는 다릅니다.
